# Third-party assets

The vector path data in the `vector/*.kt` files was converted (via the
Valkyrie CLI) from the SVG sources of the **Yaru Icons** theme, part of
[ubuntu/yaru](https://github.com/ubuntu/yaru) (`icons/src/fullcolor`).
